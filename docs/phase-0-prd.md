# Sci Feature PRD v1（Phase 0 输出）

## 1. 产品目标
构建面向个人科研工作者的 Web 应用，支持从文献检索、阅读整理、关系图谱到综述写作建议的一体化闭环。

## 2. 核心用户
- 硕博研究生
- 博士后
- 青年教师

## 3. MVP 范围
1. 文献入库（手动 / DOI）
2. 文献标签管理
3. 阅读笔记卡片
4. Paper-Author-Tag 关系图谱基础视图
5. 综述写作工作区（骨架）

## 4. 关键对象
- Paper
- Author
- Tag
- Note
- Relation

## 5. 成功指标（v1）
- 30 分钟内完成一个主题初步入库与标签化
- 单篇文献笔记整理时间减少 40%
- 可从图谱中定位高关联未读文献
